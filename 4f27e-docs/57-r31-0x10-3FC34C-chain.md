| #   | Predicado                              | Notas                                                                    |
| --- | -------------------------------------- | ------------------------------------------------------------------------ |
| A   | `r31==0` ∧ `3FBF54==0.25` ∧ `3FC350≠0` | não consulta `3FBBB0`                                                    |

## Impacto

O bit `3FC34C` (liga/desliga S28=`184F28` vs `0xFF`, doc 55) é um **one-hot de classificador**, não um eixo de mapa.  
Com packer `3FDA6A` morto, o estático empurra o default para **ligado via timer `3FD79D`**. Contraprova = dump (diferido) de `3FC34C` / `3FBBB0` / `3FDA6A`.

`3FC188` (byte de modo `0x2B`/`0x2C` no caso `0x10`) vira float `3FC18C` @ `0x9571C`. Não escolhe tabela 1D.
